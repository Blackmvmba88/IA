# TOKYO — Deterministic Movement Compiler

TOKYO compiles time/astronomical intent into a resolved mechanical movement graph.

Pipeline:

READ → VALIDATE → PLAN → RESOLVE → CERTIFY → COMPARE → EXPORT

The compiler does not emit production G-code. It resolves kinematics, geometry constraints,
coordinate frames and deterministic manifests.

## Target class

Dense astronomical/high-complication movements with:
- hours / minutes / seconds
- moon / year / orbital cycles
- rotating cages / tourbillon carriers
- coaxial and offset displays
- layered radial/axial placement
- deterministic manufacturing references

## Core invariant

Equivalent input intent must produce the same resolved movement hash.
